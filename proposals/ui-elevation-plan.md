# 514cc Console · UI 视觉跃迁计划

> 目标：把 `apps/control-center` 从「工程质量合格的专业控制台」推到「Awwwards / FWA / CSSDA 每日最佳同等品质」的先锋数字体验。
> 图标纪律：Lucide 单一来源，界面全程零表情符号。
> 编制时间：2026-09-04

---

## 零、结论先行

**核心判断：不能把控制台做成艺术站，要做的是「密度守恒，冲击力加在抬头处」。**

这是 16 个面板、1150 个 DOM id、987 处 `text-xs` 的高生产力控制台。强行放大字号、堆留白、上全屏滚动叙事，等于摧毁可用性。Awwwards 级作品真正做文章的地方，从来不是让用户操作的区域，而是用户**抬头**的时刻。

因此本计划采用 **叙事层注入（Narrative Layer Injection）**：

| 层 | 承担 | 设计参数 | 处置 |
|---|---|---|---|
| **叙事层** | 首屏 / 空状态 / 面板过渡 / 成果页 / 数据可视化 | 24–72px · 流体 clamp · 衬线展示体 · 编排动效 | 全部创意预算 |
| **骨架层** | 导航 / 表单 / 列表 / 按钮 / 输入框 | 12–15px · 密度守恒 · 无衬线 · 仅功能动效 | 冻结，不做装饰 |

好处是**冲击力增长不以效率为代价**：骨架层一个像素都不动，可用性零风险。

## 一、现状盘点（实测，非印象）

### 1.1 已达标的资产（不要重做，要用起来）

| 资产 | 实测状态 | 判断 |
|---|---|---|
| `forge/tokens.css` | 163 个唯一变量，OKLCH 色彩空间，明暗双主题逐令牌对照，含排版阶 / 间距 / 半径 / 阴影 / 动效 / z-index 全维度 | **武器库是满的** |
| Lucide 图标 | 143 个 `<symbol>` 离线 sprite，`lucideIcon()` 调用 262 处 + 静态 `<use>` 246 处 | 已统一 |
| Emoji 纪律 | 用户可见字符串中 **0 处**（仅注释内 12 处彩色符号） | 已达标，改为**锁死** |
| 高级渲染 | `atelier-canvas.js` 指针响应式粒子星座、`hero-starmap.js` 库仑斥力力导向星图，均已启用 | 已有地基 |
| 工程门禁 | `ui:lint`（含 baseline）、`qa:ui` 套件、`run-tests.mjs` 自清 | 回归保障在 |
| 既有治理 | `proposals/ui-triage-report.md` 已完成断点 / 空状态 / 密度三档的工程卫生治理 | 承接，不重复 |

### 1.2 三重失衡（这才是真问题）

**失衡一 · 排版坍塌**

令牌从 12px 到 44px 全都有，消费端却几乎全压在最小档：

| 令牌 | 12px | 13px | 14px | 15px | 16px | 20px | 24px | 30px | 36px | 44px |
|---|---|---|---|---|---|---|---|---|---|---|
| 引用次数 | **987** | 169 | 42 | 16 | 29 | 19 | 21 | 9 | 4 | **2** |

全站字号天花板 **19px**，`clamp()` 仅 29 处，`--font-editorial` 衬线展示体仅 7 处消费。
→ **没有排版层级，就没有视觉冲击力。** 这是最高效的单点杠杆。

**失衡二 · 层叠失控**

- `.main-content` 在 `styles.css` 中被**重复定义两次**（L598 padding `24px 26px 32px` / L8641 padding `16px 18px 18px`），后者静默覆盖前者。
- atelier 氛围层的 `mesh` / `orb` / `grain` 被 `experience-polish.css:18-22` 与 `art-direction.css:54-58` **双双 `display:none`**，且两者结论不一致（前者连 canvas 一起关，后者保留 canvas）。
- 24 张 CSS 靠固定加载顺序定优先级，无成文层叠契约。

→ **写了不生效、改一处坏一处。** 不先治理，后续所有视觉改造都是在流沙上施工。

**失衡三 · 动效散装**

48 个 `@keyframes` + 271 条 `transition` 全散落，无编排；`animation-timeline` / `scroll-timeline` / `view-timeline` **0 处**；无视差、无自定义光标、无动画库（亦无需引入）。
→ 静态感强，缺「活体」质感。

**附带发现**：`body { overflow: hidden }`，`.main-content` 是唯一全局滚动容器 —— 这正是滚动驱动动效的挂载点，且是**尚未开垦的空白红利**。

## 二、六个改造维度

### D1 · 排版双轨制（收益最大，优先做）

建立两条互不干扰的排版轨道：

- **UI 轨**（xs→base，12–15px）：骨架层专用，保持不变。
- **展示轨**（2xl→7xl，24–72px）：叙事层专用，新增。

动作：
1. 扩 `tokens.css`：`--text-6xl` / `--text-7xl`，并新增 **fluid clamp 排版标量**（`clamp(min, calc(Xrem + Yvw), max)`），消灭 29 处手写尺寸。
2. 让 `--font-editorial` / `--forge-display` 衬线展示体接管标题层，消费从 7 处提到 40+ 处。
3. 落地顺序：首屏 `view-overview` → 16 处空状态 → 视图标题 → 关键指标数字 → 数据可视化标题。

验收：字号天花板 19px → ≥72px；展示轨消费 ≥40 处；明暗双主题对比度全部 ≥ WCAG AA。

### D2 · 动效编排层（从散装到体系）

1. **收敛**：48 个 keyframes 归纳为约 12 个语义化编排原语（enter / exit / stagger / morph / reveal / pulse…），统一消费已有的 `--dur-*` 与 `--ease-*` 令牌。
2. **切换编排**：View Transitions API 接入 16 个面板切换 —— 这是用户每天触发几百次的动作，收益最直接。
3. **滚动驱动**：`animation-timeline` 挂 `.main-content`（当前 0 处），用于视图内长内容的渐进揭示。
4. **降级**：全程尊重 `prefers-reduced-motion` 与项目已有的 `data-motion="reduce"` 开关。

### D3 · 材质与光场（激活被关掉的资产）

1. **先修冲突**：为 atelier 五层定单一真源，删除 `experience-polish.css` 与 `art-direction.css` 中重复的 `display:none`，恢复 mesh / grain。
2. **重建三层材质**：gradient mesh（渐变场）+ feTurbulence grain（噪声材质）+ canvas 粒子（已启用），从「装饰」升格为贯穿明暗双主题的**材质语言**。
3. 约束：材质层在任何情况下不得降低文字对比度，需过 AA。

### D4 · 图标体系（已达标 → 扩展 + 锁死）

现状已经达标，本维度重点是**别退步**：

1. **扩展**：143 → 约 220 图标，覆盖本轮新增的叙事层场景。
2. **立档**：16 / 20 / 24px 三档尺寸，stroke 1.5 / 1.75 / 2 三档线宽，形成语义层级。
3. **微动效**：关键图标加 `stroke-dasharray` 描边 draw-in —— 这是线形图标体系最锋利的杀手锏。
4. **门禁**：扩 `ui:lint` 规则，**禁止任何 emoji / 表情符号进入用户可见字符串**（当前 0 处，锁死防回潮）；同时禁裸值，颜色字号必须走令牌。

### D5 · 先锋交互装置（「惊艳」的真正来源）

- 磁吸按钮（magnetic hover）
- 文字逐字揭示 + 遮罩上推揭示
- 自定义光标（磁吸 / 形变，仅桌面端，尊重 reduced-motion）
- 数据可视化统一语言：现有手写 sparkline（L4342）、健康度环形（L4396）升维为一致的图表体系
- **Hero 时刻**：`view-overview` 作为第一印象页重点打造

硬约束：**装置不得阻碍操作** —— 点击热区不变小、响应不延迟、键盘可达性不退化。

### D6 · 工程治理（否则改一处坏一处）

1. 修 `.main-content` 重复定义。
2. 制定并写入 `forge/README.md` 的**层叠契约**：24 张 CSS 各自负责什么、谁覆盖谁。
3. 扩 `ui:lint`：emoji 门禁 + 裸值（硬编码颜色 / 字号）门禁。
4. UI 回归基线：每 Wave 结束后跑 `qa:ui` + 截图基线比对。

## 三、分波次路线

| Wave | 主题 | 关键动作 | 验收标准 |
|---|---|---|---|
| **W0** | 地基与门禁 | 修 `.main-content` 重复定义；定层叠契约并清理 atelier 冲突；`ui:lint` 加 emoji + 裸值门禁；16 面板 × 明暗 × 三档密度截图基线入库 | `ui:lint` 0 违例；`qa:ui` 全绿；基线快照可比对 |
| **W1** | 排版革命 | 双轨排版落地；fluid clamp；衬线展示体接管标题；先打首屏 + 16 处空状态 | 字号天花板 ≥72px；展示轨消费 ≥40 处；可读性回归通过 |
| **W2** | 动效编排 | keyframes 收敛为编排原语；View Transitions 接入 16 面板；滚动驱动挂 `.main-content` | 切换有编排感；reduced-motion 自动降级 |
| **W3** | 材质光场 | 重建 mesh + grain + canvas 三层；明暗双主题调校 | 两种主题下材质可辨且不干扰文字，过 AA |
| **W4** | 先锋装置 | 磁吸 / 逐字揭示 / 自定义光标 / 图表语言统一 / Hero 页 | 装置不缩小热区、不延迟响应、键盘可达 |
| **W5** | 逐面精修 | 16 面板按使用频次排序逐个精修，每面一次回归 | 全量 UI 回归 + 可用性自查 |

**排序理由**：W0 必须最先（否则在流沙上施工）；W1 其次（单点杠杆最高、风险最低、视觉收益最大）；W4 装置最「惊艳」但风险最高，故排在地基与排版之后。

## 四、风险与红线

| 风险 | 缓释 |
|---|---|
| 视觉改造击穿可用性 | 骨架层冻结；装置不得缩小热区 / 延迟响应 |
| 层叠冲突导致写了不生效 | W0 先定契约；每次改动后跑 `qa:ui` 与截图基线 |
| 大字号破坏高密度布局 | 展示轨仅在叙事层生效，不进入列表 / 表单 / 按钮 |
| 动效引发性能或眩晕 | 尊重 `prefers-reduced-motion`；canvas 已有 DPR 上限与 `visibilitychange` 停帧 |
| 回归失控 | 每个 Wave 独立验收，失败不进入下一 Wave |

## 五、待拍板决策

1. **冲击力度档位**
   - A 保守：只做叙事层（推荐，零可用性风险）
   - B 激进：骨架层也引入材质（半透明导航、浮起卡片）
   - C 先锋：骨架层也做实验性布局（有可用性代价）

2. **Wave 优先级**
   - 推荐 W1 排版优先（杠杆最高、风险最低）
   - 或 W4 装置优先（更惊艳，但地基未稳）

3. **改造范围**
   - 16 面板全量
   - 或先聚焦高频 5 个：overview / workbench / bot / team / config
